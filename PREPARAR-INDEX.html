🎓 ConcursorIA Tech — Preparar PWA

Este utilitário altera somente a configuração de instalação do aplicativo original, sem editar questões, aulas, tokens ou dados de usuários.

1. No GitHub, baixe o arquivo index.html atual do repositório MotoForce/concursoIA2.1.
2. Escolha esse arquivo abaixo.
3. Clique em Gerar index atualizado.
4. Envie o novo index.html e os cinco arquivos PWA à raiz do GitHub.

Segurança: o HTML escolhido é processado exclusivamente no seu navegador. Nenhum arquivo é enviado a um servidor por este utilitário.
